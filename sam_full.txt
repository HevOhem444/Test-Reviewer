PART I — INTRODUCTION TO SYSTEM & NETWORK ADMINISTRATION
System Administration: Management, maintenance, and support of computer systems, servers, and IT infrastructure to
ensure reliable and secure operation.
Key responsibilities: Install operating systems; create user accounts; manage permissions; perform backups; apply
updates and patches; troubleshoot system problems.
Memory: System Admin = Systems / Servers / Software
Network Administration
Focuses on managing network devices and communication between systems.
Key responsibilities: Configure routers and switches; manage IP addressing; monitor network performance; maintain
connectivity; implement network security; troubleshoot network issues.
Memory: Network Admin = Network Devices / IP / Connectivity
System Administrator vs Network Administrator
System Administrator Network Administrator
Manages servers Manages routers & switches
Creates users Configures IPs
Maintains operating systems Configures VLANs
Performs backups Monitors traffic
Installs applications Configures routing
Enterprise Network Overview
Internet fi Router fi Switch fi PCs / Servers
Router: connects different networks.
Switch: connects devices in a LAN.
Firewall: filters and protects traffic.
Server: provides services to clients.

Career opportunities: System Administrator, Network Administrator, IT Support Engineer, Cloud Administrator.
PART II — OPERATING SYSTEM INSTALLATION & CONFIGURATION
Hardware Assessment
--- PAGE 2 ---
Before installation, confirm CPU speed, RAM capacity, and disk space meet OS requirements. Cross-reference hardware
with manufacturer specifications to avoid driver and firmware conflicts. Prepare bootable USB/DVD media or configure a
network PXE server.
Pre-Installation: Three Critical Decisions
1. Boot Sequence: Configure BIOS/UEFI to prioritize installation media.
2. Installation Strategy: Choose Clean Install, Upgrade, or Multi-boot.
3. Deployment Environment: Decide between physical hardware and virtualization.
Disk Partitioning
Partitioning divides a physical disk into logically independent volumes. MBR is legacy, has a 2 TB limit, and supports up to
four primary partitions. GPT is modern and supports larger disks. An extended partition can contain multiple logical
partitions. A swap area is a dedicated partition used for virtual memory.
File Systems & Formatting
Formatting: prepares a partition to store system files.
NTFS: default for Windows; supports encryption, compression, and large volumes.
ext4: standard for Linux; reliable, journaling-enabled, and widely adopted.
Installation Process
1. Launch Installer: Windows setup.exe or Anaconda on Linux distributions.
2. Regional Settings: language, time zone, keyboard layout, and regional preferences.
3. Licensing: enter product key and verify software licensing.
Initial System Configuration
Network: configure IP addressing, DNS, and firewall/security policies.
System Services: enable essential services and set startup parameters.
Startup Optimization: use msconfig (Windows) or systemd (Linux) to disable unnecessary background tasks and improve
boot time.
User & Group Account Management
Principle of Least Privilege: users should only have the access they need.
Administrator: full system control; use sparingly and protect with strong credentials.
Standard User: limited privileges reduce risk.
Guest: temporary, highly restricted access; should be disabled in production.
User Groups: organize users to manage permissions efficiently.
Maintenance & System Security
Updates & Patches: install critical OS updates to close known vulnerabilities.
System Logs: monitor kernel events, service failures, and security incidents.
Admin Tools: Device Manager and Disk Cleanup help maintain hardware health and free storage.
System Lifecycle
1. New: freshly installed, fully patched, optimally configured.
2. Configured: customized for production; routine defragmentation and error checking applied.
3. Degraded: performance declining; verify backups and assess hardware for replacement.
4. Renewed: re-imaged, upgraded, or replaced to restore integrity and performance.
Memory: New fi Configured fi Degraded fi Renewed
